# Open Skies

A 3D flight simulator that runs in a web browser. You fly a Cessna 182T Skylane over an island with two airfields, a lakeside town, a port and a scattering of villages. Real lift, drag, stalls and landing gear.

## Files

- `blue-yonder.html` — the game. One file; open it in a browser (it loads Three.js from the internet).
- `model-builder.html` — Open Skies Workshop, a page for building your own planes and buildings out of simple shapes. Copy a model's code there and paste it into the game's Settings under "My models".

## Controls

| Key | What it does |
|---|---|
| Mouse | Gentle steering: right/left to roll, down to pull up, up to push down |
| W / S | Nose down / nose up |
| A / D | Roll left / right |
| Shift / Ctrl | Throttle up / down |
| Q / E | Rudder, and steering on the ground |
| F | Flaps |
| T / G | Trim nose up / down |
| Z | Cruise: holds your height automatically |
| Space | Wheel brakes |
| L | Landing lights |
| V | Mouse steering on / off |
| C | Change view |
| M | Big map |
| O | Settings (time of day, weather, my models) |
| N | Next airport |
| X | Sound |
| P | Pause |
| R | Restart on the runway |
